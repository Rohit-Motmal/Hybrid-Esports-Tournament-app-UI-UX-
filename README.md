# Hybrid Esports – Tournament App UI/UX

A mobile UI/UX concept that brings esports tournaments and mind-game competitions together in one place. The design explores how players can discover tournaments, review event information, register, and keep track of their events.

**Project type:** UI/UX design concept

## Problem

Players may need to search in different places to find tournaments for different games. It can also be difficult to keep track of events they have registered for. This concept explores one place to discover and manage tournament participation across multiple game categories.

## Design goals

- Bring multiple game categories into one mobile experience.
- Make tournament discovery and registration easier to follow.
- Show useful event details before registration.
- Provide a place to review upcoming and past events.
- Keep account and preference options accessible.

## Main features shown in the designs

- Home screen with tournament search and a featured/live tournament.
- Game categories: Free Fire Max, BGMI, chess, and checkers.
- Tournament listing and mode selection.
- Registration form for player/game details.
- Registration confirmation summary.
- Upcoming and past event views with check-in information.
- Profile, account settings, notifications, game preferences, and logout.

## Design workflow

1. Identify the problem and intended users.
2. Define the main app sections and user flows.
3. Design the mobile screens and visual interface in Figma.
4. Connect screens into a clickable prototype.
5. Review the flow and identify improvements.

See [Project Overview](docs/PROJECT_OVERVIEW.md) and [Design Process](docs/DESIGN_PROCESS.md).
